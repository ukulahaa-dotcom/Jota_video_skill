# Image Prompt JOTA V6.0.0 — sederhana, kamera sesuai adegan

**Versi:** V6.0.0 • 8 November 2026 • Pengganti V5 rear-only.

Owner memperlihatkan contoh dua anak **berhasil faceless menggunakan instruksi sederhana**, dengan **front three-quarter**. Aturan untuk gambar baru:

1. Di **kalimat pertama**, tulis: **KEEP FACELESS FOR ALL CHARACTERS. Every face is completely smooth with no eyes, no nose, and no mouth.**
2. Jelaskan **kamera sesuai storyboard**; tidak boleh memaksakan belakang. SHOT04 secara eksplisit **front three-quarter two-shot**.
3. Sebutkan jumlah tokoh, usia, tinggi relatif, pakaian, pose tangan, letak properti, dan latar singkat.
4. Wajah adalah bidang kulit polos asli, bukan masker. Jangan mengarang jenggot atau kacamata.
5. **Enhance Image Prompt OFF**, Creative Mode OFF, public gallery OFF, Image Type 3D, 9:16.
6. Setelah library VideoExpress dihapus pemilik, jangan memakai referensi lama dan jangan mengklaim preview sebagai file library yang dapat dipakai video. Setiap PNG wajib QC visual terlebih dahulu.
7. Jangan memindahkan kamera, membuat benda tambahan, atau mencampurkan petunjuk prop yang saling bertentangan.
