# Paket penulisan ChatGPT pada Mac —1.0.0

Owner memilih naskah dan prompt dari sesi ChatGPT. Jalur ini tidak menghubungkan langganan ChatGPT ke API dan tidak memanggil penulis lokal/OpenRouter. Manager Telegram dapat tetap memakai GPT mini. Permintaan naskah baru di Telegram berstatus chatgpt_pending sampai paket dari sesi owner tersedia.

Paket schema jota.authoring-draft.v1 memuat10shot6detik pada pilot, cast/desain, komposisi, awal/aksi/akhir, transisi, narasi dan prompt gambar/animasi mandiri. CLI resmi local/jota.mjs authoring-import <gpt/reviews/.../storyboard.json> <NEW-PROJECT> membuat brief/shots dari validatorstickmanexisting dan menyimpan exact authored prompts beserta sourcehash. File HTML hanya tampilan; jangan mengantre HTML. Source berubah atau proyek tujuan sudah ada ditolak; buat revisi baru. Tidak mengubah prompt/aset/proyek lama.

Authoring-bridge memakai antrean/updateQueue, worker/slot/login dan library existing. Tahap pertama auxiliaryproject-REF berisi acuan CROC dan RIVER_ENVIRONMENT tanpa manusia: expected_heads=0 menghitung kepala stickman manusia; benda/setting/gaya tetap diperiksa. Flag authoring_reference_only berlaku hanya presetstickman, zerocharacters/cast/heads, auto=false dan video_after_qc=false. Hanya tahap desain manusia yang dilewati, bukan QC atau approval. Acuan menjadi usable hanya setelah cekShotQc + library save/reload/readback/hash + independentface + localvisualcalibration lolos. Fixture tests bukan QC sebenarnya.

Bridge menyalin bukti referensi dan bytes yang sama ke proyek baru dengan origin_project, preset/project/mediaId/name/library/hash nyata. Animal insert03/07 memakai CROC+bukti lingkungan sebagai refbenda/ruang; shotdua manusia memakai dua refmanusia agar tidak mengarang kapasitasUI. Tidak ada mixedhumans+animalshot pada pilot. Persetujuan style/profile tetap stickman-v1; bukan dukungan untuk semua hewan/gaya. Keberhasilan realanimal/QC harus dibuktikan dari job saat berjalan.

Setelah refs lolos, antrean gambar proyek utama melakukan character-firstBUDI/JOTA melalui mekanisme existing. Additional approved subjectrefs tidak dihapus saat humanrefs terpasang. Semua gambar/QC harus lolos sebelum animasi; progressive_video=false pada brief. AudioElevenLabs, SFXfoley bertiming, native mute, ffmpegassembly dan Drive tetap pipelineexisting. Temporal QC dan retry/REVIEW tetap. preserve_prompts menghentikan penulisan ulang oleh model pada QC gagal dan melaporkan kebutuhan revisi ChatGPT; tidak menghapus catatanFAIL atau resetretry. Semua publishinglocked.

Koordinator berjalan di tick telegram-factory existing, bukan poller/producer baru. QUEUED/RUNNING/QC/REVIEW bukan MP4selesai. Importer diuji lewat generator/validatoractual, isolasitemp, dedupe, sourcechanged, missing/staleQCblock dan noauthoringmodelcalls. Laporan live harus membedakan refbaru terantre, asetrefterbukti, scene, clipQC dan MP4Drive.

## Koreksi dari uji nyata acuan pertama

Prefix tubuh stickman untuk gambar lingkungan mengundang tokoh tak diinginkan; surface-screen lama juga menilai kepala buaya sebagai kepala manusia. Tidak meloloskan aset itu. Flag nonhuman_subject hanya sah untuk people=none/castkosong/expected_heads0, dengan NONHUMAN_STYLE tanpa instruksi badan manusia. Profilcartoon-subject-v2 mewajibkan human_heads, animal_count dan subject_profile pada schema, independent surface hanya menghitung kepala manusia, lalu benda/identitas/anatomi/gaya/setting diperiksa dari gambar nyata. Kalibrasi nyata positifbuaya dan negatifstickman-manusia harus lolos di samping kalibrasi manusia lama; failure tidak diubah menjadiPASS. Buaya acuan harus memperlihatkan anatomiquadruped; occlusionterencana submerged pada scene hanya menerima NA untuk bagian terendam, tidak mengaku kaki tersembunyi terverifikasi. Crop tangan SHOT05 memakai metadata hands_only: tetap dua referencecast, nol kepala terlihat dan tepatdua tangan milik sleevebiru/oranye. Tidak menuntut kepala/kaki di luar framing, tetap menolak kepala/tangan ekstra atau identitas takjelas.

Reference-only boleh menjalankan QC tanpa video_after_qc; tidak boleh submit klip/reviewvideo untuk aset acuan. Koreksi acuan dilakukan melalui authoring-ref-revise, proyekREF-R2/R3 baru dengan seluruh sejarahbukti dan batasmaks3generasiacuan, hanya jika tidak ada workeraktif atau aset scene utama. Mainbrief/shots boleh dikompilasi ulang sebelum scene apa pun dibuat, snapshotversisebelumdipertahankan. Setelah sceneada wajib proyekrevisi baru, tidak menimpaaset. Narasi/promptowner tetap dipertahankan; versi2 paket hanya metadataframing. Kalibrasipositifbuaya/negatifhuman v1 gagal karena enumprofileopsional hilang, v2requiredschemaPASS; kedua log dipertahankan, bukan melonggarkan QC.

PadaREF-R2, independent screen sudah membuktikan nol kepala manusia, tetapi scalar genericheads di observer dihitung sebagai satu kepala buaya, bertentangan dengan alasan tertulisnya sendiri. Jangan mengubah nilaiitu menjadiPASS. Schema nonhumanv2 menghapus fieldheadsambigu dan mewajibkan human_heads sertaanimal_countterpisah; rawobservasi asli tetap disimpan. Referensi sama diperiksa ulang lewat qc-images, bukan digenerateulang, dengan arsipbefore-human-heads-v2 dan reservasiQCattemptbaru yang tetapdibatasi3. Profillegacyhuman memakaiheadsseperti semula. Pipelineacuan tidak mengizinkan video; sourceR2versi2 tetapdua generasiacuan, technicalruntimevalidatorcachefailuresebelumgambar didamaikan lewatcommandIDbaru setelahidleworkerreload, tidak mengubah atau meresetattemptlama.
