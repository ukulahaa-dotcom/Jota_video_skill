# JOTA Video Production skill

Versi aktif selalu yang tertulis di frontmatter `SKILL.md`. File ini tidak mencatat nomor versi supaya tidak basi.

Skill untuk memproduksi video JOTA: gambar acuan dari VideoExpress, Artistly, atau ChatGPT Images (dipilih owner), semua video bergerak di VideoExpress. Repo: `ohan78/Jota_Content_Factory` (private).

Mulai dari [`SKILL.md`](SKILL.md). Itu satu-satunya sumber aturan utama.

## Isi folder

| Folder/file | Isi |
|---|---|
| `SKILL.md` | Aturan inti, mode, jalur kerja, alur produksi, QC, daftar playbook |
| `references/CONSISTENCY_RULES.md` | Wajib setiap produksi: SAMBUNG atau KEYFRAME, bible tokoh dan benda, peta lokasi, buku keadaan, blok KAMERA, cek konsistensi |
| `references/SCENE_WORKFLOW.md` | Folder proyek, karakter acuan, SC01, metode KEYFRAME dan SAMBUNG, generate paralel, BLOK KUNCI, pembuka dan penutup, QC, peta UI VideoExpress |
| `references/STYLE_CATALOG.md` | 40 style video dengan style tag siap tempel, termasuk manekin dan kartun wajah polos untuk JOTA 1 |
| `references/CAMERA_LANGUAGE.md` | Ukuran shot, sudut, gerakan kamera, lensa, pola adegan |
| `references/` lainnya | Mode kreatif, kunci provider, aturan faceless, kebijakan sumber Islam, edukasi, lisensi, riset sumber luar |
| `playbooks/` | Tujuh kategori konten (PB01 sampai PB07) dan proyek yang sedang berjalan di `productions/` |
| `presets/` | Format platform dan preset pelajaran |
| `templates/` | Brief episode, brief pelajaran, ledger produksi, ledger klaim sejarah Islam |
| `examples/` | Contoh paket cerita dan pelajaran (bukan perintah produksi) |
| `evals/` | Checklist anti-kesalahan |
| `archive/v2/` | Versi lama, hanya sejarah |
| `CONNECT.md` | Cara memakai skill ini dari Claude atau ChatGPT |

## Status

Dokumentasi. Mengedit atau membaca skill ini tidak menjalankan generate apa pun. Produksi hanya berjalan saat owner memerintahkan di sesi aktif.
