# JOTA Video Ideas — User Approval Gate

**Current owner-approved planning ideas (2026-10-21): PB05 “Misteri Al-Hijr” and PB06 “Fir'aun: Kesombongan dan Kekuasaan”. See [APPROVED_INDEX.md](APPROVED_INDEX.md). No other proposed topics have been approved.**

## Two states only
1. **PROPOSED:** The assistant offers a small, categorized shortlist **in the chat**. Nothing enters the production queue or this GitHub ideas directory. A proposal is not consent to make a video.
2. **APPROVED_FOR_PLANNING:** After the owner selects an exact idea, save a compact approved idea brief to `ideas/approved/IDEA-ID.md` **within the selected playbook** (e.g. `../language-learning/ideas/approved/`), including category, user-approved title/topic, angle, target audience, learning/moral takeaway, recommended length, sensitivity/source needs, and reference to approval conversation when accessible. Never store private child photos/names. Approval of topic alone does **not** authorize media generation.

## Authorizations stay separate
- `APPROVED_FOR_PLANNING`: may create scripts, research, storyboards, and prompt plans.
- `GENERATE_AUTHORIZED`: separately given explicit order authorizing media generation, exact scope and acceptable costs.
- `OWNER_APPROVED_MEDIA`: owner accepts a verified candidate after QA.
- `PUBLISH_AUTHORIZED`: separate explicit direction with destination/account/visibility and exact candidate.

No themes from documentation examples (e.g. older family story, Qur'anic research case, Arabic sample) are automatically declared owner-approved episode ideas. Backlogs and templates also do not imply production permission. Do not start a background agent, charge credits, or publish based on repository contents.
