# JOTA platform delivery presets (proposed, not tested provider limits)

**Creative-mode overlay mandatory:** select `JOTA_1` or `JOTA_2` before any new video; this file sets duration/framing but never selects facial/music rules. See [`CREATIVE_MODES.md`](../references/CREATIVE_MODES.md). References below describing faceless/no music are **JOTA 1 examples only**; for JOTA 2 use permitted expressive faces, licensed music, supported lip-sync and corresponding QA. Technical/provenance/privacy gates stay shared.

## JOTA-YT-SHORTS-2D
- Intended channel: YouTube Shorts. Portrait 9:16, authored portrait-safe from storyboards rather than naïve crop.
- Default planned episode: 35–60 s (creative target only, not a platform maximum).
- Visual: readable bold silhouette, one clear action per clip, original painterly 2D cinematic Indonesian setting, titles optional **as editor text only**, never as AI-generated signage.
- Narration: Indonesian, no visible lip-sync, no music. Story: engaging first moments, one moral tension and payoff, original closing.
- Scene grid and voice timings generated by actual audio duration, not arbitrary constant clips.
- Mode-conditional full visual QC and universal privacy/rights gates apply; JOTA 1 additionally requires all-frame faceless/no music.

## JOTA-YT-LONGFORM-2D
- Intended channel: YouTube landscape narrative episodes. Landscape 16:9, composition re-authored for wide.
- Target length configured per brief, e.g. 5–10 min, **not** an automatic default or entitlement.
- Narrative arcs split into chapters, continuity/world bible across chapters, scene ledger that supports idempotent resume, varied shot scales and measured visual rhythm. Avoid repeated stock animation.
- Requires extra rights, factual integrity, detailed pacing, narration cadence, throughput/credit feasibility checks. Long-form planning DOES NOT authorize mass generation.

## JOTA-CINEMA-16x9-60S
- Use for a **60-second cinematic landscape movie**: script-only time target 00:00–01:00, native VideoExpress project/export target landscape 16:9 and 1920×1080/24 fps **only when current provider capabilities verify those settings**. Not the same framing as a 9:16 short or a 5–10 minute long-form episode.
- Plan ten ~6-second shots as an initial editing grid, but measure actual actor dialogue and supported generated clip durations; change the grid if necessary and verify final export length. Require original 2D painterly art, wide establishing/medium/reaction/action coverage, 180-degree geography lock and physical motion on screen; reject repeated still-card zooms.
- **DIALOGUE-ONLY is a narrative choice in both modes**: distinct in-world character voices with no narrator unless the owner requests one. `JOTA_1`: faceless humans/animals, no lip-sync or music. `JOTA_2`: expressive speaking faces and supported lip-sync permitted; music allowed only when properly licensed/desired. Verify native audio/editor capabilities. Use `../references/SCENE_WORKFLOW.md` with the selected mode; character speech is native in the same job.
- Mandatory image approval before per-shot generation, all-frame QA and private VideoExpress native export provenance. Public release needs separate owner authorization.

## JOTA-SHORTS-COMPILATION
- Derivative compilation only from rights-cleared JOTA originals with owner approval, new narrative/editing value, and disclosure review. No repetitive low-effort aggregation.
